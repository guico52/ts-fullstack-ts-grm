# 项目迁移

模板不附带开发过程中产生的历史 SQL。首次开发必须使用空数据库，在仓库根目录运行 `bun run db:dev -n init`，从当前模型生成初始 SQL 并应用到数据库。

审查生成的 SQL 后提交到新项目的版本控制。这些文件是项目的正式迁移记录，不属于应当清理的模板残留。后续模型变更运行 `bun run db:dev -n <变更名称>` 生成新的记录。

已有迁移时，新开发库、独立测试库和部署环境使用 `bun run db:deploy` 应用已提交的迁移，不重复生成初始迁移。

已应用的项目迁移不得随意修改或删除。`db:push` 不记录 SQL，仅用于临时结构实验，不用于项目初始化、常规开发或生产数据库。
